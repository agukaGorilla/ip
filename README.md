# Baymax

Baymax is a personal task manager that helps you keep track of your daily ToDos, Deadlines, and Events through a streamlined JavaFX GUI.

### Key Features:
* **Task Management:** Create, delete, mark, and unmark tasks.
* **Persistent Storage:** Tasks are automatically saved to and loaded from the local hard drive.
* **Search & Filter:** Find tasks by keywords or view your schedule for a specific date.
* **Friendly Syntax:** Use short command aliases (t, d, e, del, etc.) for faster data entry.

### System Requirements:
* Java 17

### How to Run:
1. Download the `Baymax.jar` from the Assets below.
2. Open a terminal and navigate to the download location.
3. Run the command: `java -jar Baymax.jar`
4. Check the latest release and documents for more detailed user instructions.
